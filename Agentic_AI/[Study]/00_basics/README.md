# LLM 요소
모델은 컨텍스트(전역적)와 토큰(국소적)을 계산하며 샘플링 파라미터에 따라 출력값이 달라진다

일부 모델은 지원하지 않을수 있으며 재현성이 완벽하게 이루어지지 않는다

주요 파라미터:
* Temperature : 확률분포를 제어하여 가능성이 낮은 토큰 등장비율을 조절한다(낮을수록 전형적인 답변을, 높을수록 창의적인 답변을 출력)
* Top-K : 토큰 후보의 수 상한치
* Top-P : 샘플링 할 확률분포 임계값
* Repetition Penalty : 반복되는 토큰에 패널티를 주어 중복 구문 방지
