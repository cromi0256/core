AI 안전 및 윤리는 인공 지능 시스템이 인간의 복지, 공정성, 투명성을 최우선으로 하는 방식으로 개발, 배포 및 사용되도록 보장하기 위한 지침과 모범 사례를 수립하는 것을 포함한다.

여기에는 편향, 사생활 침해, 의도하지 않은 결과와 같은 위험을 해결하고, 복잡한 환경에서도 AI가 안정적이고 예측 가능하게 작동하도록 보장한다.

잘 알려진 AI 안전 문제:

1. 프롬프트 인젝션 :
   - 악의적인 입력으로 의도하지 않거나 해로운 결과를 생성하도록 조작하는 방식
   - 프롬프트 주입 공격은 모델의 예상되는 동작을 변경함으로써 모델이 민감한 데이터를 노출하거나 부적절한 응답을 생성하도록 유도한다

2. 보안과 프라이버시 :
   - 개인정보와 같은 민감한 데이터가 수집, 처리, 저장 과정에서 안전하게 관리되어 무단 접근 및 유출을 방지한다
   - 아울러 모델의 편향성, 데이터 오용, 그리고 AI 의사결정 과정의 투명성 확보에 대한 우려도 제기되고 있다

3. 편향과 공정성 :
   - 모델이 차별적이거나 왜곡된 결과를 산출하지 않도록 보장해야 하는 과제
   - 편향 : 균형한 훈련 데이터, 잘못된 가정, 또는 편향된 알고리즘에서 비롯될 수 있으며, 이로 인해 인종, 성별 또는 기타 요인에 기반하여 특정 집단이 불공정한 대우를 받게 될 수 있다.
   - 공정성 : AI 시스템 내의 편향을 탐지, 완화 및 방지하는 기술을 개발함으로써 이러한 문제를 해결하는 것을 목표로 한다
  
# 안전 모범 사례
1. [컨텐츠 검토 API](https://platform.openai.com/docs/guides/moderation) : 혐오 발언, 폭력, 자해, 성적 암시적 콘텐츠 등과 관련된 사전 정의된 정책 위반 사항을 식별
2. 적대적 테스팅 수행 : 모델의 견고성을 평가하고 취약점을 파악하기 위해, 의도적으로 기만적이거나 변형된, 혹은 정교하게 조작된 입력 데이터를 모델에 노출시키는 과정
3. 견고한 프롬프트 엔지니어링 : 구체적인 지침, 예시 또는 구조화된 형식을 제공함으로써 모호성을 최소화하고 명확성을 극대화하는 데 중점을 둔다
4. 고객 이해 : 사용자의 목표에 부합하도록 조정하는 동시에, 설계된 용도 외의 상황에서 사용이 제한되도록 안전 장치를 마련
5. 입출력 제한 :
   - 입력 제한 : 입력 제한은 유효하고, 정제되며, 형식이 올바른 데이터만 모델로 입력되도록 보장하여 오류를 줄이고 성능을 향상
   - 데이터 유형 제한, 값 범위 설정, 특정 포맷 지정
   - 출력 제한 : 모델이 적절하고 안전하며 관련성 있는 결과를 산출하도록 보장
   - 출력 길이를 제한하거나, 답변 형식을 지정하거나, 유해하거나 편향된 응답을 방지하기 위해 필터적용
