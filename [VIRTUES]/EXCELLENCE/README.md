탁월함은 미래를 내다보는 안목에서 나온다.

단지 지금 이 순간만을 위한 선택이 나중에 몇 배의 빚이 되어 돌아올 수 있다.

성과가 기대에 부응하지 않은 경우, 전략적인 행동이 필요할 때다.

# 나의 탁월함
갑작스런 충동으로 후회될 행동은 하지 않는다.

`욕구`는 자연스럽지만 불확실성을 가늠해봐야한다.

총체적인 판도를 읽기 위한 갬빗은 훌륭한 전략이다.

# AI의 시대에서
AI는 현재의 요청에 적절히 대답할 뿐이다.

숨겨진 의도나 파급력은 잘 이해하지 못 하며, 귀찮은 잔일을 처리하기엔 좋다.

한마디로 직감은 없지만, 일반적인 상황에 빠르고 좋은 파트너다.

# 남들과의 탁월함
어느 팀이든 나중가면 거기서 거기인 성과를 보인다.

사람의 생각과 행동도 결국 정체되기 마련이기에 유의미한 변수가 되지 못 한다.

이러한 의미에서 나는 집단보다 단독생활을 선호한다.

# 탁월하지 않는 사회
비난을 받더라도 사명을 갖고 행동하는 위인은 이제 없다.

모두들 안정된 환경을 추구하며, 이를 거스르는 행동에 제약을 건다.

도전적 행동의 실패에 책임을 지기 싫어하고, 남들이 자신을 넘어서지 못 하도록 끌어내리기만 할뿐이다.

# 탁월한 프로그래밍
빠르고, 저렴하고, 취약점 없는 코드가 탁월함을 만든다.(간결하면 더 좋겠지만)

AI가 코드를 작성시키되 효율성과 보안, 그리고 운영은 사람이 맡는다.

역설적이게도 코드를 직접 작성해야 그 점이 보이기에 프로그래밍은 죽지 않는다.
