2. [유용한 내장 라이브러리](https://docs.python.org/ko/3.14/tutorial/stdlib.html)

`re` : 정규표현식 조작

`datetime` : 시간 데이터 처리

`math` : 수학 함수

`itertools` : 이터레이터 함수

`pathlib` : 파일 시스템 제어

`zipfile` : 압축파일 조작

`hashlib` : 보안 해시 생성

`argparse` : cli 파서

`threading`, `multiprocessing` : 병렬처리

`asyncio` : 비동기 처리

`typing` : 타입 힌트

`unittest` : 유닛테스트, 

`sys` : 시스템 접근
