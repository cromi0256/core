## 일반
GitHub를 기반으로 하여 안정적인 코드 운영을 돕는다.

**CI** : 여러 개발자가 push한 코드에 이상이 있는지 검토

**CD** : 검토 완료된 코드를 사용자에게 자동으로 배포

이를 통해 새로운 코드를 빠르게 검토하고 배포하도록 한다.

## 고급
MLOps에서는 모델에 새로운 데이터를 학습시켜 모델 성능 변화를 감지하는데 있다.

특히, MLOps 1단계에서 핵심적인 역할로 기존 파이프라인을 기반으로 신속히 학습시키고 배포한다.

이 단계에서의 목표는 자동화 파이프라인 설계와 구축이다.
