# 일반
머신러닝 및 딥러닝 모델 개발을 위해 MLflow는 머신러닝 라이프사이클을 관리하는 도구다.

**MLflow 주요기능**
1. 실험 추적 — 실험 전반에 걸쳐 모델, 매개변수, 지표 및 평가 결과를 추적
2. 모델 평가 — 실험 추적 기능과 통합된 자동화된 평가 도구
3. 모델 레지스트리 — ML 모델의 전체 수명 주기를 협업하여 관리
4. 배포 — Docker, Kubernetes, Azure ML, AWS SageMaker 등에서 모델을 배치 및 실시간 평가

## 고급
**실험 추적** : 프로젝트 단위인 Experiment에 runs를 통해 메타데이터(파라미터, 지표, 실행시간)와 아티팩트(모델 가중치, 데이터셋, 환경설정)를 저장

**모델 평가** : test셋 평가 지표 시각화는 물론, SHAP 해석, 플러그인을 통해 그 이상의 작업도 가능

**모델 레지스트리** : 버전 컨트롤, 모델 계보&추적, 배포 워크플로우, 거버넌스를 관리하고 협업

**배포** : 로컬 추론은 물론, 컨테이너화를 통해 프로덕션 환경에서의 배포가 용이
