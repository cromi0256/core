클라우드 컴퓨팅은 서버, 스토리지, 데이터베이스, 네트워킹 및 소프트웨어를 포함한 컴퓨팅 리소스를 인터넷을 통해 제공하는 것으로, 제3자 제공업체가 필요에 따라 제공한다.

이것이 없다면 개발자의 제한된 컴퓨팅 자원으로 24/7 안정적으로 작동해야하며 불가능에 가깝다.

## 📖 사전 지식
* Python, Linux, Bash, Git/GitHub : 소프트웨어 개발과 운영
* Networking 기초 : IP주소, 서브넷, 포트, 프로토콜(TCP, UDP, HTTP, HTTPS), DNS
* Cybersecurity 기초 : 암호화 알고리즘, 방화벽, 인증서, 인증과 승인(Authentication/Authorization)
네트워크와 사이버보안은 디자인을 담당

* 프라이빗 클라우드 : 단일 조직 전용 인프라로, 사내 또는 코로케이션 시설에 호스팅 됨
* 하이브리드 클라우드 : 퍼블릭+프라이빗
* 멀티 클라우드 : 여러 퍼블릭 클라우드 사용

## 클라우드 인프라
1. 데이터 센터
* 네트워크 토폴로지 : 수많은 서버가 원활하게 대량의 데이터를 주고받을 수 있도록(Non-blocking), 장애 상황에도 멈추지 않으며(Redundant), 변화하는 클라우드 작업량에 맞춰 소프트웨어로 유연하게 제어할 수 있도록(Software-configurable) 설계됨
* 업스트림 연결성 : 데이터 센터와 공용 인터넷을 연결하는 방식
* 랙, 포드, 통로 : 서버를 효율적인 공간 배치, 전력 분배, 냉각하는 구성요소
* 전력&냉각 : 전력은 이중화된 전원 공급 장치, 무정전 전원 공급 장치(UPS) 및 디젤 발전기를 통해 공급되므로 단일 장애로 인한 정전이 발생하지 않도록 보장; 냉각은 하드웨어를 안전한 작동 온도 범위 내로 유지(상당한 에너지 소모)
* 무인 운영 : 하드웨어는 원격으로 모니터링, 관리되며, 많은 경우 수리도 가능

2. 가상머신
* 하이퍼바이저 : 단일 물리적 머신에서 여러 가상 머신을 실행하는 데 사용할 수 있는 소프트웨어
![image](https://www.stackscale.com/wp-content/uploads/2023/02/Hypervisors-stackscale.jpg)
* VM 마이그레이션, 라이브 마이그레이션 : 가상 머신을 물리적 호스트, 스토리지 또는 클라우드 환경에서 다른 곳으로 이동시키는 기술; 라이브 마이그레이션은 서비스(VM)를 끄지 않고(무중단) 실행 상태 그대로 다른 호스트로 이동

3. 컨테이너
* 도커 : 컨테이너 이미지 빌드, 컨테이너 실행, 수명주기 관리 플랫폼
* 가상머신과 컨테이너 차이점 : 가상 머신은 하드웨어 수준에서 가상화를 수행하고 컨테이너는 운영체제(OS) 수준에서 가상화를 수행한다
![image](https://dam-cdn.atl.orangelogic.com/AssetLink/8rey324iqvflta48it3i685ys31yv4wj.png)

4. 데이터베이스
* 관리형 관계형 DB : ACID 보장, 자동 백업 및 다중 가용 영역 장애 조치를 지원하는 SQL 호환 스토리지
* NoSQL DB : 키-값 쌍, 문서, 와이드 컬럼 또는 그래프와 같은 다양한 형식으로 데이터를 저장

5. 인스턴스 타입
* 가상머신 인스턴스 : CPU(+GPU), 메모리 및 네트워크 대역폭을 용도에 맞게 설정
* 베어메탈 클라우드 : 최대 I/O 성능, 낮고 예측 가능한 지연 시간이 요구되는 워크로드 또는 라이선스나 규정 준수 제약으로 인해 가상화 환경에서 실행할 수 없는 워크로드에 중요

6. 스케일링
* 자동 스케일링 : 수요에 따라 실행 중인 인스턴스 수를 자동으로 조정
* 스팟&예약 인스턴스 : 스팟 인스턴스는 내결함성과 중단 가능성을 갖춘 워크로드를 요구하는 반면, 예약 인스턴스는 정확한 용량 계획이 필요

## 클라우드 네트워킹
1. 네트워크 핵심
* 가상 프라이빗 클라우드(VPC) : 클라우드 제공업체의 인프라 내에서 사용자가 정의하는 논리적으로 격리된 네트워크
* 서브넷 : 하나의 거대한 네트워크(VPC)를 논리적으로 분할한 작은 네트워크 조각
* 라우팅 : 네트워크 트래픽이 출발지에서 목적지까지 이동하는 경로를 결정하는 프로세스
* NAT : NAT 게이트웨이는 아웃바운드 트래픽을 위해 프라이빗 IP 주소를 공용 IP 주소로 변환하여, 외부에서 접근할 수 없으면서도 인터넷으로 나가는 요청(업데이트 다운로드, 외부 API 호출 등)을 함
* IP 관리 : VPC가 커짐에 따라 주소 공간 고갈을 방지하기 위한 탄력적 IP 할당(고정 공용 IP), IPv4와 IPv6 계획, CIDR 블록 크기 조정 등을 포함
* VLAN & VXLAN : 가상 근거리 통신망(VLAN)은 물리적 네트워크를 계층 2에서 격리된 논리적 네트워크로 분할; 가상 확장형 LAN은 이더넷 프레임을 UDP 패킷 내에 캡슐화하여 레이어 2 네트워크를 레이어 3 IP 패브릭 위로 확장
* Software-Defined Networking(SDN) : 물리적 하드웨어를 건드리지 않고도 VPC, 동적 라우팅, 네트워크 정책 및 가상 어플라이언스를 구현하여 네트워크 토폴로지를 프로그래밍 방식으로 관리
![image](https://www.brainz.co.kr/_res/namo_editor/binary/images/000001/Nw==.png)
* VPN & 직접 연결 : VPN은 암호화 된 트래픽 터널링으로 설치가 빠르고 비용이 저렴하지만 인터넷 트래픽과 대역폭을 공유; 직접 연결은 온프레미스 인프라와 클라우드 간에 전용 사설 회선을 제공하여 더 낮고 안정적인 지연 시간, 더 높은 처리량, 그리고 공용 인터넷 혼잡에 대한 노출 방지를 제공

2. 트래픽 관리
* DNS : 도메인 이름을 클라우드 리소스로 변환하며 기본적인 A 레코드 관리 이상의 기능을 제공
* 로드밸런서 : 들어오는 트래픽을 여러 백엔드 인스턴스에 분산하여 단일 서버가 병목 현상을 일으키는 것을 방지
* 방화벽 & 보안 그룹 : 보안 그룹은 개별 인스턴스 또는 네트워크 인터페이스에 연결된 상태 저장형 가상 방화벽. 포트, 프로토콜, 소스 IP 또는 보안 그룹별로 허용되는 인바운드 및 아웃바운드 트래픽을 정의
* CDN & 엣지 캐싱 : CDN은 정적 및 캐시 가능한 콘텐츠(이미지, 스크립트, 비디오, API 응답)를 최종 사용자와 지리적으로 가까운 서버에 배포하여 지연 시간을 줄이고 원본 서버의 트래픽 부하를 분산; 엣지 캐싱은 CDN 계층에 응답을 저장하므로 반복적인 요청은 원본 서버를 거치지 않고 처리

## 클라우드 스토리지
1. [스토리지 타입](https://aws.amazon.com/ko/compare/the-difference-between-block-file-object-storage/)
![image](https://d2908q01vomqb2.cloudfront.net/e1822db470e60d090affd0956d743cb0e7cdf113/2020/07/21/Figure-2-On-premises-storage-decision-matrix-a-decision-matrix-flowing-downwards-with-applications-access-protocols-and-decisions.png)
* 오브젝트 스토리지 : 데이터 자체, 메타데이터, 고유 식별자로 구성된 오브젝트로 백업, 미디어 파일, 로그, 정적 웹사이트 자산 및 데이터 레이크의 원시 데이터 저장을 위한 기본 선택지
* 블록 스토리지 : 낮은 지연 시간과 높은 IOPS를 제공하므로 데이터베이스 볼륨, 운영 체제 디스크 및 빠른 임의 읽기/쓰기 액세스가 필요한 모든 워크로드에 적합
* 파일 스토리지 : 연결되는 블록 스토리지와 달리 파일 스토리지는 여러 인스턴스에서 동시에 마운트할 수 있으므로 공유 애플리케이션 데이터, 콘텐츠 관리 시스템 및 공통 파일 시스템이 필요한 HPC 워크로드에 적합
* NAS, SAN : NAS는 NFS 또는 SMB 프로토콜을 사용하여 네트워크를 통해 파일 수준 스토리지 액세스 제공; SAN은 전용 고속 패브릭을 통해 블록 수준 스토리지 액세스를 제공

2. 데이터 생애주기
* 스토리지 클래스 및 티어링 : 핫티어, 콜드티어, 아카이브 티어로 구분됨; 검색 속도와 비용은 반비례함
* 보존 및 규정 준수 : 데이터 보존 정책은 데이터를 저장해야 하는 기간과 삭제 시점을 정의; 규정 준수 요건(GDPR, HIPAA, SOC 2, PCI DSS)은 데이터 저장 기간, 접근 제어, 암호화 및 감사 로깅에 대한 특정 규칙을 부과
