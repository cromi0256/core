클라우드 컴퓨팅은 서버, 스토리지, 데이터베이스, 네트워킹 및 소프트웨어를 포함한 컴퓨팅 리소스를 인터넷을 통해 제공하는 것으로, 제3자 제공업체가 필요에 따라 제공한다.

이것이 없다면 개발자의 제한된 컴퓨팅 자원으로 24/7 안정적으로 작동해야하며 불가능에 가깝다.

## 📖 사전 지식
* Python, Linux, Bash, Git/GitHub : 소프트웨어 개발과 운영
* Networking 기초 : IP주소, 서브넷, 포트, 프로토콜(TCP, UDP, HTTP, HTTPS), DNS
* Cybersecurity 기초 : 암호화 알고리즘, 방화벽, 인증서, 인증과 승인(Authentication/Authorization)
네트워크와 사이버보안은 디자인을 담당

## 클라우드 모델
1. 클라우드 배포 모델:
* 퍼블릭 클라우드 : 클라우드 서비스 제공업체(CSP)가 소유하고 관리하는 인프라를 여러 고객과 공유하는 클라우드 컴퓨팅 모델
* 프라이빗 클라우드 : 단일 조직 전용 인프라로, 사내 또는 코로케이션 시설에 호스팅 됨
* 하이브리드 클라우드 : 퍼블릭+프라이빗
* 멀티 클라우드 : 여러 퍼블릭 클라우드 사용

2. [클라우드 서비스 모델](https://cloud.google.com/learn/paas-vs-iaas-vs-saas?hl=kr) : 제공 범위에 따라 구분됨
![image](https://www.gstatic.com/bricks/image/Zpw-v4ZOiAkbLm9ARSl68tGaZFYsFsz1ABwRbl8Cj_ozj12jCTPmgVGKBARz3Xwum1CUsMQ7Hog.jpeg)

3. 제공업체 생태계:
* 하이퍼스케일러 : 대규모 글로벌 클라우드 제공업체(AWS, GCP, Azure)
* 지역 클라우드 : 소규모 지역 클라우드(데이터 거주, 지연시간, 비용 등의 이유로 채택)
* 개발자 특화 : 소규모 팀에 적합한 간단한 서비스 제공
* 관리형 쿠버네티스 : 쿠버네티스 특화 클라우드 제공업체(Civo, Vultr)
* 제공업체 종속 : 지나친 의존으로 다른 업체로 떠나기 어려워지는 현상; 특히 데이터베이스, 서버리스 플랫폼, AI API가 해당
