# 프롬프트 엔지니어링
모델이 더 나은 대답을 할 수 있도록 효과적인 지시에 초점을 맞춘다

1. 제로샷 : 아무런 예시 없이 모델에 지시
2. 퓨샷 : 몇가지 예시를 들어 출력 형식을 조정
3. ReAct : 생각-행동-관찰의 구조로 에이전트 시스템에 효과적
4. CoT : 중간 추론 과정을 출력하게 하여 논리적 오류를 줄임
5. 입력 형식 : JSON같은 파일로 입력을 주어 오류낮은 일관된 출력을 유도
6. 함수 호출 : 모델이 특정 함수를 사용하여 정확한 출력 유도
7. 프롬프트 캐싱 : 이전 지시를 저장함으로써 반복되는 작업에 속도향상과 비용절감
8. 스트리밍 응답 : 응답을 실시간으로 부분 전송함으로써 사용자 경험 개선(반대 : 배치응답)
9. 시스템 프롬프팅 : 모델의 전체 동작 방식을 정의하여 세션 전반에 걸쳐 일관되고 통제되며 구조화된 AI 응답을 보장
