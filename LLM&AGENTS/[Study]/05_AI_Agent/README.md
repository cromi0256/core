“에이전트”란 주변 환경을 인식하고, 의사 결정을 내리며, 특정 목표를 달성하기 위해 행동을 취하는 자율 시스템이나 구성 요소를 의미한다.

에이전트는 복잡한 작업을 수행하기 위해 외부 시스템, 사용자 또는 다른 에이전트와 상호작용한다.

모델, 도구, 지시사항으로 구성되어 있으며 목적 달성까지 에이전트 루프를 실행한다.

Agent Loop :
1. 사용자 입력(인지) : 사용자의 요구사항 이해
2. 추론 및 계획 : 적절한 해결 방법을 찾고 단계적으로 계획
3. 행동(도구호출) : 도구를 선택하고 계획을 실행하여 결과를 반환
4. 관찰(성찰) : 진행 단계와 결과를 살피며 현재 상태를 갱신하고 오류를 찾아 우선순위를 재정렬
