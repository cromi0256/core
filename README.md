# core
머신러닝을 시작으로 다양한 분야의 컴퓨터 사이언스 역량을 기르고 있습니다

완벽히 알기보다 업무의 흐름에 따라, 필요에 따라 배워갑니다

학습은 공식문서와 [로드맵.sh](https://roadmap.sh/), [freeCodeCamp](https://www.youtube.com/@freecodecamp)를 이용합니다

업무:
