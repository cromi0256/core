SQL(Structured Query Language)은 관계형 데이터베이스 관리 시스템(RDBMS)에 저장된 데이터를 관리하고 조작하는 데 사용되는 프로그래밍 언어이다.

이를 통해 데이터를 조회, 삽입, 수정, 삭제할 수 있을 뿐만 아니라, 데이터베이스 스키마를 정의하고 데이터에 대한 접근 권한을 제어할 수도 있다.

SQL에 대한 기본적인 이해는 거의 모든 데이터베이스와 상호작용하기 위한 기초가 된다.

# 기초
1. 관계형 데이터베이스 :  데이터를 행과 열로 이루어진 2차원 표(테이블) 형태로 저장하고, 여러 테이블 간의 상호 연결(관계)을 통해 데이터를 관리하는 방식
2. 관계형 데이터베이스 관리 시스템 : 테이블로 정리하고, 키를 사용하여 이러한 테이블 간의 관계를 설정
  - 장점 : 제약 조건과 ACID 속성(원자성, 일관성, 격리성, 내구성)을 통해 데이터 무결성을 보장하는 등 여러 이점을 제공하며, 신뢰할 수 있는 트랜잭션을 보장
  - 단점 : 방대한 데이터 세트의 경우 확장성에 한계가 있을 수 있으며, 경직된 스키마로 인해 비정형 또는 반정형 데이터를 처리하는 데는 최적의 선택이 아닐 수 있음
3. SQL과 NoSQL :
  - SQL : 구조화된 스키마와 테이블을 사용하며, 데이터 무결성과 조인을 통한 복잡한 쿼리를 중시
  - NoSQL : 데이터 구조 면에서 더 큰 유연성을 제공하지만, 확장성과 성능을 위해 일관성을 어느 정도 희생
