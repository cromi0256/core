## 일반
LLM을 단순 챗봇을 넘어 도구를 쥐어주고 일을 시킬 수도 있다.
그렇지만 독심술사는 아니기에 좋은 결과물을 바란다면 좋은 지시가 필요하다.
워크플로에서 품질을 크게 좌우하는 것은 프롬프트다.

좋은 프롬프트 작성법:
1. 원하는 것을 구체적으로 적는다
2. 배경 사실, 제약, 목표 등의 맥락을 제공한다
3. 도메인과 관련된 기술 용어를 사용한다
4. 짧은 예시를 사용한다
5. 초안 이후 잘못된 점, 놓친 점, 혼란스러운 점을 하나씩 고쳐나간다
6. 출력물의 크기나 형식을 명시한다.
