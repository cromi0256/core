## 일반
딥러닝은 인공신경망을 사용하며 더 많은 파라미터를 다루고, 워크플로우는 정형데이터와 비슷하다.
간단한 이미지,텍스트 분류나 시계열 예측은 ML로도 가능하지만 고급 작업에는 충분치 않다.
DL모델은 다음과 같은 특성이 있다.
* 입출력으로 정형데이터 뿐만 아니라 텍스트, 사진, 오디오, 동영상, 문서 등 확장성이 높음
* 이미지의 경우 객체감지, 시맨틱분할, 인스턴스분할 등 분류 외의 작업 가능
* 시퀀스를 받아 시퀀스를 출력(seq2seq)
* 분석형 AI를 넘어 학습된 모델로 새로운 데이터 만드는 생성형 AI
* 강화모델 설계
* LLM > AI Agent 파운데이션 모델을 파인튜닝하여 작업 보조

## 고급
딥러닝은 이 많은 것을 처음부터 설계하지 않는다.
AlexNet, BERT, GPT, AlphaGo 등 사전훈련된 모델을 받아 파인튜닝 하여 목적에 따라 사용한다.
그럴지라도 몇몇 개념은 이해하고 사용하는 편이 좋다.
**주요개념**
* 텐서
* 배치
* 활성화 함수
* 학습률
* 옵티마이저
* 정규화
* 드롭아웃
