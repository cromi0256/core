## 일반
BERT, T5, GPT-1 등의 자연어 처리 학습 사전 모델 이후, 사람과의 자연스러운 소통을 가능케한 LLM이 등장했다.
GPT-5, Gemini, Claude 등 대형언어모델은 대량의 데이터를 처리하여 학습한다.
**LLM의 학습과정**
1. 데이터 수집 : 책, 기사, 웹사이트 등의 출처로부터 텍스트 데이터 코퍼스 수집
2. 정제 : 오류, 중복, 콘텐츠 점검 등의 전처리
3. 토큰화 : 기계가 읽을 수 있는 단위인 토큰으로 분할
4. 학습 : 다양한 임베딩 방법과 어텐션 매커니즘을 활용하여 자기지도 학습
LLM은 대량의 데이터와 컴퓨팅 자원을 소모하므로 초기비용이 높아 파운데이션 모델을 조정하여 쓰는편이다.

## 고급
좀 더 사용자의 요구에 맞는 대답을 받으려면 추가작업이 필요하다.
첫째, 도메인에 특화된 작업의 데이터를 가져와 미세조정을 한다.
둘째, 프롬프트 엔지니어링을 통해 지시사항대로 답변을 유도한다.
LLM은 할루시네이션이라는 치명점이 존재하여 정확성을 요구하는 작업에는 주의한다.
