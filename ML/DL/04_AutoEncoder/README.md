## 일반
CNN이 데이터를 압축하는데 이를 다시 풀어보면 어떨까?
오토인코더는 이런 인코더-디코더 구조에 원본 입력을 재구성 하도록 설계되어있다.
**오토인코더의 구조**
1. 인코더 : 입력보다 적은 수의 노드를 통과하여 더 작은 차원으로 압축한다
2. 잠재 공간(병목) : 여러 인코더를 거쳐 가장 압축된 차원의 레이어다
3. 디코더 : 인코딩 된 잠재 공간을 압축 해제하여 원본 형태로 재구성한다
이 신경망은 비지도학습으로 입력을 정답으로 보고 재현된 결과물의 재구성 오차로 학습한다.

## 고급
PCA도 저차원으로 데이터를 압축하지만, 오토인코더는 비선형데이터에도 적용할 수 있어 고차원 데이터에 더 적합하다.
입력을 학습하기에 이상 탐지에도 쓰일 수 있고, 손상된 이미지 복원이나, 노이즈 처리에도 우수하다.
VAE는 압축된 표현을 확률 분포로 학습하는 생성형 모델로 새로운 데이터를 생성한다.
