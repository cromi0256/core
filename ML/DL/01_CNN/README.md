## 일반
이미지는 채널, 높이, 너비로 이루어진 3차원 텐서로 컬러사진은 torch.Size([배치크기, 3, 높이, 너비])로 배치를 처리한다.
컨볼루션 신경망은 컨볼루션 계층, 풀링 계층, 완전 연결 계층을 거쳐 이미지의 패턴을 식별한다.
데이터 처리는 간단히 설명하자면 아래와 같다.
1. 컨볼루션을 통해 커널(필터)로 특징을 잡아낸다
2. 풀링을 거쳐 데이터를 압축한다
3. 위의 과정을 여러번 거친다
4. 최종적으로 완전 연결로 이미지를 분류한다

## 고급
더 나은 분류 성능을 바란다면 몇가지의 과정이 더 필요하다.
이미지를 변형을 하여 데이터를 증강시킨다.
간단하게는 좌우를 뒤집는 것으로도 좋은 성능을 내며 CutMix기법을 사용하여 더 나은 성능을 기대할 수 있다.(물론 훈련시간도 늘어난다)
다양한 사전학습모델을 파인튜닝하여 앙상블한다.
최종 추론 단계에서도 증강시켜 소프트보팅을 한다.

원본데이터, 모델, 증강기법에 따라 결과는 매우 다양하며, 긴 시간의 GPU학습을 필요로 하므로 성능과 비용에 적절한 균형이 필요하다.
