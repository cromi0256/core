## 일반
CNN이 이미지 픽셀간의 패턴을 감지했다면, RNN은 출력간의 패턴을 감지한다.
즉, 과거의 결과가 미래에 영향을 주거나, 반대로 현재의 결과로 과거를 알수도 있다.
순서의 패턴을 감지하기에 시계열 예측, 자연어처리, 음성인식 등에 쓰인다.

**순환신경망의 유형**
1. RNN : 지정된 길이의 시퀀스를 입력 받아 다음 스텝 예측
2. BRNN : 미래의 결과를 가져와 현재 상태를 예측('식은 *먹기'처럼 '먹기'는 '죽'이란 단어를 예측하는데 도움을 줌)
3. LSTM : 장기 종속성 문제를 해결하고자 입력 게이트, 출력 게이트, 망각 게이트를 도입
4. GRU : LSTM의 경량화 버전으로 리셋 게이트, 업데이트 게이트로 효율적인 학습

## 고급
이런 신경망으로도 결국 장거리 종속성, 병렬처리 병목 현상으로 쓰이지 않는 추세다.
어텐션 매커니즘을 기반으로 한 트랜스포머가 월등한 성능을 내기 때문이다.
시계열 예측의 경우에도 ML의 그래디언트 트리 계열이나 prophet이 더 나은 성능을 보장한다.
물론 좋은 성능을 내려면 패턴을 잘 감지하도록 전처리가 중요하다.
